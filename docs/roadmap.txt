一、v0.1+ 待办清单（§12.1）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
项       说明
--gh-only 模式    ghpat start --gh-only 后 daemon 拒绝 get_pat 请求，仅服务 gh 子命令；适用于不需要 git push 的纯 Agent 场景，彻底关闭 PAT 外流通道
cred-helper 一次性 ticket  wrap 时 client 向 daemon 申请短时效（30s）随机 ticket 放入子进程环境，cred-helper 须携带方可换取 PAT；配合审计日志，缓解 Agent 任意探测
--json GraphQL 字段对齐     映射层将 REST 字段转为 gh 的 GraphQL 命名（head.ref→headRefName 等），并补齐 reviewDecision、additions 等列表接口缺失字段（需额外 GraphQL 调用）
TOKEN_EXPIRED 复核清除      收到业务 401 后自动向 /user 复核，确认 401 Bad credentials 才标记失效并清除（v0.0.1 保守地一律不清除）
SSH remote 支持   引入 SSH agent 协议代理，超出现有 PAT 范畴，独立设计
